# AIOStreams — reproduce the reference runtime configuration

This document is part of the required installation procedure in the root `README.md`.
The AIOStreams database is intentionally **not** copied. The settings below are reconstructed from the current reference export and must be recreated on a fresh instance after the bootstrap `.env` has been filled.

Never copy API keys, encrypted credentials, UUIDs or service passwords from another installation. Use the values generated for the new installation.

## 1. Bootstrap variables

Before first start, complete `data/aiostreams/.env` as described in the root README. Important relationships:

- `BASE_URL` = your public AIOStreams URL.
- `SECRET_KEY` = a fresh 64-character hex key. Do not change it after configs have been created.
- `AIOSTREAMS_AUTH` and `AIOSTREAMS_AUTH_PERMISSIONS` define the operator account(s).
- `BUILTIN_JACKETT_API_KEY` must be the API key generated by your fresh Jackett instance.
- `COMET_PUBLIC_API_TOKEN` must equal Comet's `PUBLIC_API_TOKEN`.
- `FORCED_SERVICE_CREDENTIALS` must contain your own TorBox key and AIOStreams auth.
- TMDB/TVDB credentials must be your own.

The proxy topology already present in the template is deliberate:

```text
socks5h://gluetun:1081
http://gluetun:8889
socks5h://warp:1080
http://gost:8082
```

## 3. Base filtering and sorting

Set the reference configuration as follows.

### Preferred order

- Resolutions: `2160p, 1440p, 1080p, 720p, 576p, 480p, 360p, 240p, 144p, Unknown`
- Qualities: `BluRay REMUX, BluRay, WEB-DL, WEBRip, HDRip, HC HD-Rip, HDTV, DVD REMUX, DVDRip, SCR, TC, TS, CAM, Unknown`
- Languages: `Italian, English, Original, Dual Audio, Multi, Dubbed, Unknown`
- Subtitles: `Italian, English`
- Visual tags: `HDR+DV, DV, HDR10+, HDR10, HDR, HLG, 10bit, SDR, IMAX, Upscaled, AI`
- Audio tags: `Atmos, DTS:X, TrueHD, DTS-HD MA, FLAC, DTS-HD, DTS-ES, DTS, DD+, DD, OPUS, AAC`
- Stream types: `usenet, stremio-usenet, debrid`
- Encodes: `AV1, HEVC, AVC, VC-1, Unknown, XviD, DivX`
- Exclude visual tags: `3D, H-OU, H-SBS`

### Result and media limits

- Global result limit: **20**, conjunctive mode.
- Movie maximum size: **100 GB**.
- Series maximum size: **100 GB**.
- 2160p movie maximum size: **100 GB**.
- Global bitrate ceiling: **250 Mbps**, using metadata runtime; the variants below impose the practical 50/10 Mbps caps.
- SeaDex support: enabled.
- Do not globally exclude uncached streams.

### Matching

- Year matching: enabled, tolerance `1`, strict for movies, use initial air date.
- Title matching: enabled, mode `exact`, threshold `1`, ambiguous results `keep`.
- Season/episode matching: enabled and strict.
- Episode-title matching: disabled.

### Deduplication

- enabled: yes
- multi-group behavior: `aggressive`
- keys: `filename`, `infoHash`, `smartDetect`
- cached / uncached / P2P: `single_result`
- HTTP: `per_addon`
- library behavior: `prefer`
- smart-detect rounding: `10`
- merge: enabled
- failover variants: enabled
- merged fields: `sizes, seadex, library, subtitles, languages`

Smart-detect attributes:

`size, resolution, quality, visualTags, audioTags, audioChannels, languages, encode, edition, network, remastered, bitrate, releaseGroup`

### Sort order

Global first criterion: **cached descending**.

For cached results use:

`SeaDex -> stream-expression matched -> resolution -> quality -> library -> stream type -> stream-expression score -> language -> subtitle -> visual tag -> audio tag -> encode -> age ascending -> bitrate -> seeders`

For uncached results use:

`SeaDex -> stream-expression matched -> resolution -> quality -> seeders -> stream-expression score -> language -> subtitle -> visual tag -> audio tag -> encode -> age ascending -> bitrate`

### Other reference settings

- Poster service: RPDB; the free `t0-free-rpdb` key is sufficient if desired.
- Poster redirect API: enabled.
- Statistics: enabled at bottom; show `addon`, `filter`, `timing`.
- Hide errors: false; hide errors for `addon_catalog`, `catalog`, `subtitles`.
- Auto-play attributes: `resolution, quality, releaseGroup`.
- “Are you still there”: disabled.
- Precache next episode: disabled.
- Precache single stream: enabled.
- Preload streams: enabled; single-stream preload enabled.

## 4. Custom expressions retained by the reference setup

After applying Tamtaro, keep/add these custom behaviors:

1. **TorBox non-Pro download cap**: uncached TorBox streams over 200 GB are excluded.
2. **Protect Library & Others**: preserve library and SeaDex results and keep Smart Play pinned.
3. **Italian passthrough**: preserve Italian audio results through deduplication.
4. **Italian subtitle passthrough**: preserve results with Italian subtitles through deduplication.
5. Keep the Tamtaro quality/resolution selection expressions used by the template.

The reference deployment has the old “Final Q/R Selection” / “Final SELect Resolution/Quality” override group disabled, so do not re-enable those legacy overrides after applying the current template.

## 5. Variants

Create four variants with the following behavior. The TMDB credentials are already supplied globally from `.env`; do **not** embed them in variant scripts.

### Shared ENG (`eng`)

- enabled
- bitrate hard cap: **50 Mbps**
- required languages: `Italian, English, Original, Dual Audio, Multi, Dubbed, Unknown`
- preferred languages: `Italian, English, Dual Audio, Multi, Original, Dubbed, Unknown`
- preferred subtitles: `Italian, English`
- preserve all Italian results through deduplication
- pin at most the first **3** Italian-capable results to the top

Custom additions after removing conflicting old Italian passthrough rules:

```text
add includedStreamExpressions {
"expression": "/*Italian Preserve*/ passthrough(language(streams, 'Italian'), 'dedup')",
"enabled": true
}

add excludedStreamExpressions {
"expression": "/*Pin 3 Italian*/ pin(slice(language(streams, 'Italian'), 0, 3), 'top')",
"enabled": true
}
```

### Shared ITA (`ita`)

- bitrate hard cap: **50 Mbps**
- required language: `Italian` only
- preferred language: `Italian`
- preferred subtitles: `Italian`
- preserve Italian through deduplication
- pin at most **3** Italian results to the top

Use the same two custom Italian expressions shown above.

### Shared JPN (`jpn`)

- bitrate hard cap: **50 Mbps**
- required audio language: `Japanese`
- preferred audio language: `Japanese`
- required subtitles: `Japanese`
- preferred subtitles: `Japanese`
- require the **same result** to contain Japanese audio and Japanese subtitles
- pin at most **5** matching results

Use:

```text
add includedStreamExpressions {
"expression": "/*Japanese Audio + Japanese Subs*/ subtitles(language(streams, 'Japanese'), 'Japanese')",
"enabled": true
}

add excludedStreamExpressions {
"expression": "/*Pin 5 Japanese Audio + Japanese Subs*/ pin(passthrough(slice(subtitles(language(merge(cached(streams), type(streams, 'p2p','http','usenet','stremio-usenet')), 'Japanese'), 'Japanese'), 0, 5), 'excluded'), 'top')",
"enabled": true
}
```

Remove conflicting base language/subtitle passthrough expressions in this variant before adding the two rules above.

### `marga`

Same language/subtitle behavior as Shared ENG, but with a **10 Mbps** hard bitrate cap. Preserve Italian through deduplication and pin at most 3 Italian results.

## 6. Services

Enable:

- **AIOStreams native service**
- **TorBox**

Use only credentials belonging to the new deployment.

For the native Usenet service, configure your own NNTP provider and test authentication/playback. The reference deployment is designed around an Eweka backbone/provider; the account credentials are intentionally not part of this repository.

For TorBox, insert your own API key. The bootstrap `.env` also pins the same key in `FORCED_SERVICE_CREDENTIALS` so the service cannot be changed by normal users.

## 7. Stream proxy

Enable AIOStreams stream proxy with **MediaFlow** and use:

- URL: `https://mfp.example.com` (replace the hostname)
- public URL: same public MediaFlow URL
- credentials/password: the same value as `APP__AUTH__API_PASSWORD` in `data/mediaflow-proxy-light/.env`
- proxied services: **TorBox only**

The MediaFlow password must therefore match in AIOStreams, StreamViX and MediaFlow Proxy Light.

## 10. Final AIOStreams test

Test one movie, one normal series episode and one anime episode. Confirm all of the following before considering AIOStreams reproduced:

- Usenet results arrive from the enabled Newznab sources.
- Cached TorBox results work.
- `Shared ENG`, `Shared ITA`, `Shared JPN` and `marga` produce the intended language/bitrate behavior.
- Japanese variant returns only results with Japanese audio **and** Japanese subtitles.
- Italian results are preserved/pinned as configured.
- MediaFlow is used for TorBox when stream proxying is enabled.
- Comet Torznab and StremThru Torz answer within the 7000 ms timeout.
- Failover can cross between Usenet and debrid.
